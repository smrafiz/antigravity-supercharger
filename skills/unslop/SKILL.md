# Supercharger UI Unslop

Refactor generic, AI-slop UI components into polished, opinionated, production-grade interfaces.

## Slop Tells to Eliminate

1. **Purple/Violet Gradient Obsession**:
   - Replace generic `from-purple-600 to-indigo-600` backgrounds with intentional, brand-specific color palettes.
2. **Glowing Radial Blobs**:
   - Remove background blur circles (`blur-3xl opacity-30`) placed behind hero text without semantic purpose.
3. **Pill Badges with Emojis**:
   - Strip "✨ New Feature", "⚡ Powered by AI" pill badges.
4. **Low-Contrast Gray-on-Gray Text**:
   - Ensure readable contrast ratios (WCAG AA compliant) instead of washed-out `text-gray-400` on white or black.
5. **Over-Rounded Cards & Floating Shadows**:
   - Use crisp, structured borders (`border border-zinc-200 dark:border-zinc-800`) rather than fuzzy huge box-shadows.

## Transformation Order

Spacing -> Color Palette -> Typography -> Layout -> Micro-interactions.
