# Supercharger Strict Mode

Activates maximum caution mode. Suppresses any active autopilot window and requires confirmation prompts for all tool actions.

## Usage

- **Activate for a duration (default 1h)**:
  ```bash
  supercharger strict 30m
  supercharger strict 1h
  ```
- **Turn off**:
  ```bash
  supercharger strict off
  ```
- **Check status**:
  ```bash
  supercharger strict status
  ```
