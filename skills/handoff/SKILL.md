# Supercharger Session Handoff

Produce a complete, self-contained handoff briefing so another session or developer can immediately pick up where this session left off without context loss.

## Handoff Template

1. **Current Goal & Scope**:
   - High-level objective and constraints.

2. **Completed Actions**:
   - Exact commits, modified files, and validated features.

3. **In-Flight / Pending Work**:
   - Remaining tasks, open issues, or blocked steps.

4. **Key Decisions & Findings**:
   - Non-obvious trade-offs or codebase quirks discovered.

5. **Next Concrete Steps**:
   - Ranked list of 2-3 immediate actions to execute next.
