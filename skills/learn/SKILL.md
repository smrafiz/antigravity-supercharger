# Supercharger Learn

Distill lessons from the current session or user feedback into persistent, reusable Antigravity rules and project guidelines.

## Process

1. **Identify the Pattern**:
   - What went wrong or what convention was clarified (e.g., preferred test framework, lint style, naming pattern)?
   - Is it specific to this workspace (`.gemini/rules/`) or global across all projects (`~/.gemini/GEMINI.md`)?

2. **Formulate the Rule**:
   - Make it actionable, concise, and non-ambiguous.
   - Lead with "Always" or "Never" constraints.
   - Omit narrative filler.

3. **Persist**:
   - Write the formatted rule to the appropriate rule file or suggest adding it to the repository instructions.
